# 脱出車両と出口

マップの担当者向け: 新しいステージでは、通行可能な床に `/Game/Items/EscapeVehicle/BP_EscapeVehicle`、車で到達できる出口に同フォルダの `BP_EscapeExit` を各1個配置してください。どちらも既存の `TBEscapeVehicle` / `TBEscapeExit` を継承する配置用 Blueprint です。ネイティブクラスを直接配置しても同じ外観になります。車両と出口の両方があるステージだけが脱出ルールに切り替わり、未配置の既存ステージは電池達成時の従来勝利を維持します。

- 車は既存の `SM_ToyCar_01` を使用します。前方はローカル +X、全長110cmです。走行判定は長さ110・幅80・高さ40cmのままで、外観は約110×49×49cmです。配置時の Actor の Z は床面+20cmを基準にします。
- 出口は既存の `SM_Central_Gates` を使用します。通過方向はローカル +X、門の幅は200cm、配置時の Actor の Z は床面+100cmが基準です。門の外観には衝突を持たせず、従来どおり `ExitArea` の重なりで脱出を判定します。
- 出口の判定範囲は `ExitArea` の Box Extent で調整します。`Marker` は構築時とプレイ開始時に判定範囲の中央・幅・底面へ揃います。位置はActor全体を移動してください。外観だけのオフセットは再構築時に戻ります。車の判定幅に合わせ、出口までの経路と門の開口に余裕を確保してください。
- Demoの門は人間の開始エリア奥の壁際、Houseの門は開始エリアの側壁沿いへ配置しています。Demoは `(-135, -900, 68)`・Yaw -90度、Houseは `(790, -350, 96)`・Yaw 0度、Actor Scaleは1、ExitAreaのExtentは `(20, 60, 75)` です。門の幅は120cm、判定の奥行きは40cmで、車両の衝突形状がここへ重なると脱出します。Actor全体を動かすとExitAreaも一緒に移動します。
- 車はDemoの収納棚と机の脇 `(-710, 10, 4.15)`、Houseの本棚脇の壁際 `(250, 605, 43.1033)` に配置しています。Yawは両方-90度、Actor ScaleはDemoが0.45、Houseが1です。Demoは既存家具とダミーのおもちゃを動かさず出口まで通れるよう、全長49.5cm・判定幅36cmに縮小しています。外観は従来のリアル寄りのモデルを維持します。
- 両ステージの脱出車はMeshのMaterial Element 0に `/Game/Items/EscapeVehicle/MI_EscapeVehicleYellow` を設定しています。既存 `MI_ToyCar01` の車体塗装パラメータ `Color_Red` だけを黄色へ変更し、内装・タイヤ・窓は従来の素材を維持します。新たに配置する車にも同じ色を使う場合は、このマテリアルを指定してください。
- 収集電池は `/Game/ToyWorld/Meshes/SM_Battery_01` を使用します。見つけやすいよう高さ16cmとし、従来の底面位置を維持します。編集画面とプレイ中で同じ参照を適用します。

`/Game/CookLabels/PAL_EscapeVisuals` が上記3メッシュと配置用 Blueprint を明示的に AlwaysCook に指定します。素材パック全体を追加収録する設定は不要です。

コードで床と壁を作る検証用アリーナでは車両と出口も自動生成します。車両は `(-1500, -1000, 20)`、出口は `(2100, 1900, 100)` です。

Demo・Houseとも、必要数の電池がそろうと全員の視点が4.625秒間ラジコンに切り替わります。車の全景からヘッドライトの点灯に寄り、モーターが回って車体が少し前に動いたところで各自の視点に戻ります。人間にはラジコンの電子音とモーター音、おもちゃには実車のセルモーターとエンジン始動音が聞こえます。どちらも効果音の音量設定に従います。カメラは配置した車の向きとサイズに追従します。

おもちゃ側の音源は、magnuswaker が録音した2006年式ホンダ・アコードの始動音を演出の尺に合わせて編集したものです。素材は CC0 で公開されています。[Car Startup (Engine Ignition) — Freesound](https://freesound.org/people/magnuswaker/sounds/581082/)

演出中は両陣営の移動と搭乗を止め、試合の残り時間を保持します。終了すると最低30秒を確保して脱出を開始します。おもちゃは車にインタラクトするか触れて搭乗し、最初の搭乗者が移動操作で運転します。乗車中の視点は車の斜め後ろから旋回に追従します。Qを1回押すかインタラクトを長押しすると、車のすぐそばの立てる場所に降ります。周囲に空きがなければ乗ったままです。車で出口に入ると搭乗者だけが脱出成功となります。脱出前の時間切れは人間の勝利です。

走行速度・旋回速度・降車の長押し秒数・操作距離は `Content/Data/DA_EscapeVehicle` で調整できます。車両の既定値はこのアセットを参照し、読み込めない場合は C++ の初期値を使います。脱出開始時の最低残り時間は `DA_TBRules` の試合設定で調整できます。

## 門・車の位置を調整するとき

1. プレイを停止し、Outlinerで `Demo_EscapeVehicle` / `SH_EscapeVehicle` または `Demo_EscapeExit` / `SH_EscapeExit` のActor全体を選択して移動します。部品の相対位置とActorの位置を混同しないでください。人間の開始位置は別Actorで、門を動かしても追従しません。
2. 車のサイズ変更はActorのXYZを同じ倍率にします。Meshだけ縮めても走行判定は小さくなりません。車のActor Zは、床面 + `20 × Actor Scale` + 約2.15cmが接地の目安です。Physics Simulationは無効のままにします。
3. 車の前方はローカル+Xです。前方の発進スペース、旋回時の車体幅、降車できる空間を確保します。棚の下などは見た目が空いていても家具の当たり判定で塞がれている場合があります。
4. 門の見た目は `ExitArea` の幅と底面に自動で揃います。`Marker` だけ動かした調整は再構築で戻ります。リザルト演出の親部品 `ResultOrigin` も底面へ追従するため、演出の調整は子の `ResultCamera` / `Lineup` で行ってください。人間の入口、開始位置、開いた扉を避け、車の判定が `ExitArea` に到達できる位置にしてください。
5. 保存後にプレイを再開始し、搭乗・走行・降車・門での脱出と、再戦時に車が配置位置へ戻ることを確認します。PIE中だけの移動は保存済み配置へ反映されません。

2026-11-15の配置は、車体サイズのBox Sweepで出口までの経路と旋回、降車候補の空間、保存・再読込後の既存Actor保持を検証しました。手動での全経路の運転、NPCによる運転、ネットワーク越しの操作・視点は未確認です。
