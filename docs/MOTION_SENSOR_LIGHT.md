# 人感センサーライト

1. エディタでクラス `TBMotionSensorLight`（人感センサーライト）を探し、ステージの床面に配置する。ライトは全方向に反応するため、回転の調整は不要。
2. 調整する場合は、`Content/Data` で `TBMotionSensorLightData` 型のData Assetを作り、`DA_MotionSensorLight` と命名する。この名前なら既定で読み込まれる。別名にした場合は、配置したActorかBlueprintの `Sensor Data` に指定する。
3. 「照らされた場所を明所として扱う」をオフにすると、点灯だけが起こり、暗さによるフリーズ耐性は変わらない。Data Assetがない状態でも、既定値（オン、半径2.5メートル、設置から1秒で起動、最後の検知から3秒点灯）で遊べる。

試合中、人間はライトを見てインタラクトすると持ち上げ、もう一度インタラクトすると足元の前方に置く。前方に置けなければ足元を試し、どちらにも床がなければ持ったままになる。置いたライトは動いているおもちゃと、歩行中のニセおもちゃに反応する。壁などで遮られた位置は検知にも明所判定にも入らない。

固定配置の代わりにランダム出現させる場合は、既存の [ランダムアイテム配置](RANDOM_ITEMS.md) の手順で `TBMotionSensorLight` を候補に登録する。
